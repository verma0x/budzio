# 🎓 BUDZIO

A lightweight, responsive, and easy-to-use web application built with vanilla JavaScript, HTML, and CSS designed to help students track their daily spending, budget categories, and manage finances effortlessly—all directly in the browser.

## 🚀 Features

* **Real-Time Calculation:** Automatically updates your total expenditure instantly as you add entries.
* **Categorized Spending:** Track where your money goes (Food, Transport, College, Entertainment, and more).
* **Local Storage Integration:** Saves your data securely inside your browser so your records persist even after closing or refreshing the tab.
* **Responsive Design:** Looks clean and works seamlessly on both mobile devices and desktop screens.
* **Zero Dependencies:** Built completely with vanilla web technologies—no complex frameworks, build steps, or backend servers required.

---

## 🛠️ Built With

* **HTML5** – Page structure and semantic layout
* **CSS3** – Modern styling using CSS Variables (`:root`) and Flexbox
* **JavaScript (ES6+)** – DOM manipulation, array methods, and local storage state management
